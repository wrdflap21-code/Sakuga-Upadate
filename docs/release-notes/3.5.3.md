# Sakugaloader 3.5.3 — Security and privacy hardening

## Privacy
- The optional public relay for blocked searches (r.jina.ai) is now off by default. You can enable it in About > Privacy; the screen says who receives the search address.
- New Privacy section in About: no analytics, no tracking, and the list of services the panel talks to.

## Tools
- FFmpeg and Real-ESRGAN are downloaded in a fixed version and checked by SHA256 before use (FFmpeg 9.0.2, Real-ESRGAN 0.2.5.0).
- New installs keep tools under your user profile instead of the root of drive C. Existing installs in the old folder keep working without changes.

## License
- Sakugaloader now ships with the Sakugaloader Free Use License: free for everyone, and it cannot be sold or charged for.

## Safety
- SHA256 and ZIP checks, size limits, one update at a time, automatic backup and rollback.
- Updated third-party notices (FFmpeg and Real-ESRGAN versions, optional relay).
