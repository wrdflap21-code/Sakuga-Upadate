# Sakugaloader 3.5.5 — Cleaner layout and real folders

## Library
- Folders you create in the Folder tab are now also created on your PC, inside your Downloads folder, with the same name. Clips downloaded to a folder are saved there. Existing files are never moved, renamed or deleted.

## Layout
- Search selection bar: one main Download Selected button, centered, and a More actions menu (folder, cut, send to Upscale) with names. It no longer overlaps on narrow panels.
- Player: a clean header with the clip name, the 1 / 24 counter and Quick upscale, a single footer row with previous and next, Download and Import, and an arrow that opens the folder, cut and upscale tools. The favorite star only appears for Library clips.
- Tags stay visible below the footer.

## Safety
- SHA256 and ZIP checks, size limits, one update at a time, automatic backup and rollback.
