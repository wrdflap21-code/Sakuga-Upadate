# Sakugaloader 3.5.1 — Updates from the new repository

## Updates
- The panel now checks for updates in the official Sakuga-Upadate repository, which holds the complete panel (CEP) releases.
- The separate Sakugaloader Installer downloads this package and verifies it before installing.

## Panel
- Faster FFmpeg / Real-ESRGAN downloads from inside the panel, with clearer per-tool progress.
- Search results no longer show a favorite star on clips that are not downloaded.

## Safety
- SHA256 and ZIP checks, size limits, one update at a time, automatic backup and rollback.

Installation: use the Sakugaloader Installer (it downloads this package), or close After Effects, extract this ZIP and run `Sakugaloader-Setup.exe`. Your library, downloads and preferences are kept. The panel is not code-signed yet, so the installer enables Adobe CEP developer mode for the detected runtimes.
